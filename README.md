# CAT RAVE

A dancing cat, neon lasers, acid colors, glitch effects, and a working DJ booth. Built with plain HTML, CSS, JavaScript, and original SVG artwork. No packages to install.

Run `npm start`, then open **http://localhost:4173**. You can also open `index.html` directly in a browser. Google Fonts is optional; local font fallbacks are included.

- **Drop the meow:** a visual burst and synthesized meow when sound is enabled.
- **Chaos level:** changes the particle count, laser strength, and glitch intensity.
- **Acid / Laser / Void:** switches the visual palette.
- **Tempo:** adjusts the cat's dance and the synthesized beat from 80–160 BPM.
- **Sound:** enables an original, locally synthesized drum and bass loop. Off by default.
- **Pause / Space:** freezes animation and silences the beat.
- **Reduce effects:** removes flashing, lasers, and scrolling, with a gentler dance.
- **Fullscreen:** fills the screen when the browser supports it.

The page respects your system's reduced-motion preference and starts paused with reduced effects when enabled. Audio and animation suspend when the tab is hidden.

Run `npm run check` for JavaScript syntax checks.
